РАСХОДЫ КЕРАТИН БАРА
======================

ЗАПУСК
------
Дважды щёлкните файл «Запустить приложение.bat» — откроется окно
приложения. Всё работает ПОЛНОСТЬЮ БЕЗ ИНТЕРНЕТА: движок распознавания
чеков уже находится в папке приложения (папка vendor).

Совет: правой кнопкой по «Запустить приложение.bat» → «Отправить» →
«Рабочий стол (создать ярлык)» — и запускайте с рабочего стола.

Если приложение уже запущено, повторный запуск просто откроет ещё одно
окно — ничего не сломается.

Файл «Запуск без сервера (нужен интернет).bat» — запасной вариант:
открывает index.html напрямую, но тогда для распознавания фото чеков
нужен интернет. Основной способ — первый .bat.


ЧТО УМЕЕТ ПРИЛОЖЕНИЕ
--------------------
1. ЧЕКИ И РАСХОДЫ — вести все траты по месяцам и категориям.

2. ФОТО ЧЕКОВ С РАСПОЗНАВАНИЕМ — в окне добавления расхода перетащите
   фото чека в пунктирную рамку (или щёлкните по ней, или Ctrl+V, или
   нажмите «попробуйте на демо-чеке» — увидите, как это работает).
   Приложение само найдёт по чеку:
     - итоговую сумму (точнее всего — по QR-коду чека),
     - дату покупки,
     - название магазина,
     - подберёт категорию (косметика → «Материалы и косметика» и т.д.).
   Распознанные поля подсвечиваются зелёным — проверьте и нажмите
   «Сохранить».
   Первое распознавание после запуска занимает 10–30 секунд (движок
   инициализируется), дальше быстрее.

3. ОТЧЁТЫ ЗА ЛЮБОЙ ПЕРИОД — на вкладке отчёта выберите период:
     «Месяц» (стрелками в шапке), «Год» (стрелками возле года) или
     «Свой период» — любые даты с…по, а также быстрые кнопки: сегодня,
     этот месяц, этот год, всё время.
   В отчёте: итог по категориям (диаграмма), динамика расходов (по дням
   для коротких периодов, по месяцам или годам для длинных), печать,
   выгрузка периода в Excel (CSV). Щёлчок по столбцу динамики открывает
   этот месяц в списке расходов.

4. КАТЕГОРИИ — можно переименовывать, добавлять свои, менять цвета.

5. ДАННЫЕ И КОПИИ — резервная копия всех данных (вместе с фото) в один
   файл, восстановление, полная выгрузка в Excel, индикатор офлайн-
   готовности распознавания.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Все данные и фото остаются только на этом компьютере. Приложение
работает через локальный адрес 127.0.0.1:8177 (это ваш же компьютер,
в интернет ничего не отправляется).

ОСТОРОЖНО: если очистить в браузере «файлы cookie и данные сайтов» —
расходы удалятся вместе с ними. Поэтому раз в неделю делайте резервную
копию: вкладка «Данные и копии» → «Сохранить копию». Файл кладётся
в папку «Загрузки» — перенесите его на флешку или в облако.

Если вы пользовались предыдущей версией приложения (открывали
index.html напрямую) и уже внесли записи: откройте старый способ,
вкладка «Данные и копии» → «Сохранить копию», затем в новой версии —
«Восстановить из файла».

Если порт 8177 занят другим приложением, программа возьмёт соседний
(8178–8186). Данные привязаны к адресу, поэтому в таком случае
перенесите их резервной копией: «Сохранить копию» на старом адресе →
«Восстановить» на новом.


ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР
----------------------------
Способ 1 (одноразовый перенос): на старом ПК вкладка «Данные и копии» →
«Сохранить копию» → перенесите файл (флешка, мессенджер, почта) → на
новом ПК «Восстановить из файла» → «Объединить». Дубликатов не будет.

Способ 2 (постоянная синхронизация салон + дом): вкладка «Данные и
копии» → раздел «Синхронизация между компьютерами».
  1. Установите на оба компьютера приложение облачного диска
     (Яндекс Диск, Google Drive, OneDrive — что удобно).
  2. На ПЕРВОМ компьютере: «Создать файл синхронизации» и сохраните
     его прямо в папку облачного диска.
  3. На ВТОРОМ компьютере: «Подключить существующий файл» и выберите
     этот же файл (когда облако его передаст).
  4. Если браузер спрашивает доступ к файлу — «Разрешить», лучше
     «Разрешать при каждом посещении».
Готово: расходы, внесённые в салоне, появятся дома и наоборот
(обычно 10–60 секунд, пока облако передаёт файл). Правки объединяются
по времени, удаления тоже переносятся, дубликатов не бывает. Интернет
самой программе не нужен — только облаку.
Подойдёт и флешка вместо облака: носите файл с собой и после вставки
нажимайте «Обновить сейчас» на обоих компьютерах.

Альтернатива — скопировать всю папку приложения (включая vendor и
demo), но синхронизация через файл заметно удобнее.


ТЕЛЕФОНЫ (ANDROID И IPHONE)
---------------------------
Приложение устанавливается на телефон как обычная программа с иконкой,
камера открывается прямо в нём (кнопка «📷 Снять фото чека»).

ШАГ 1. Выложить приложение в интернет (один раз, ~10 минут):
  1. Создайте бесплатный аккаунт на github.com (Sign up).
  2. Войдите → нажмите «+» (справа вверху) → New repository.
  3. Имя: keratin-bar → выберите Public → Create repository.
  4. На открывшейся странице нажмите «uploading an existing file».
  5. Откройте папку приложения на компьютере и перетащите в окно
     браузера ВСЕ файлы сразу (index.html, sw.js, manifest.webmanifest,
     иконки, .bat, ps1 и папки vendor и demo — целиком).
  6. Дождитесь загрузки → Commit changes (зелёная кнопка).
  7. Settings (наверху) → Pages (слева) → Branch: main, папка /(root)
     → Save. Через 1–2 минуты появится адрес вида:
     https://ВАШ_ЛОГИН.github.io/keratin-bar/

ШАГ 2. Установить на телефон:
  - ANDROID (Chrome): откройте адрес → меню ⋮ → «Установить
    приложение» (или «Добавить на главный экран»).
  - IPHONE (Safari): откройте адрес → кнопка Поделиться (квадрат со
    стрелкой) → «На экран „Домой“» → Добавить.
  Появится иконка «Расходы» — приложение открывается на весь экран,
  как обычная программа, и работает даже без интернета (после первого
  запуска кэшируется).

Замечания для телефона:
- Первый запуск распознавания скачает языковые файлы (~37 МБ) — лучше
  первый раз сделать по Wi-Fi.
- Данные телефона хранятся в самом телефоне. iPhone может стереть
  данные веб-приложения, если не открывать его больше недели — поэтому
  держите включённую синхронизацию (ниже), тогда всё восстановится.
- Дополнительно: файл «Запустить доступ для телефона (Wi-Fi салона).bat»
  на компьютере салона открывает доступ по локальной Wi-Fi — телефон
  может пользоваться приложением в салоне даже без хостинга. Адрес
  показывается в окне. Вне салона он не работает.


ПЕРЕКЛЮЧАТЕЛЬ ДВИЖКА РАСПОЗНАВАНИЯ
-----------------------------------
В окне добавления чека, под кнопкой камеры, есть выбор:
  - «авто» (по умолчанию) — распознаёт офлайн на самом устройстве;
    если офлайн-файлы не найдены — автоматически через интернет;
  - «только офлайн» — никогда не выходит в интернет; если офлайн-движок
    недоступен, покажет понятное предупреждение;
  - «только онлайн» — всегда скачивает движок из интернета (нужно
    соединение).
Выбор сохраняется и применяется на каждом устройстве свой. Текущий
режим также показан на вкладке «Данные и копии».


СИНХРОНИЗАЦИЯ ЧЕРЕЗ ЯНДЕКС ДИСК (автоматически, все устройства)
----------------------------------------------------------------
Телефоны и компьютеры синхронизируются через файл на вашем Яндекс
Диске: проверка каждые 30 секунд и сразу после каждого изменения.

НАСТРОЙКА (один раз, ~10 минут, нужен аккаунт Яндекса):
  1. Откройте oauth.yandex.ru → «Зарегистрировать новое приложение»
     (войти в Яндекс).
  2. Название: «Расходы Кератин Бара».
  3. Платформы → «Веб-сервисы» → Redirect URI: вставьте адрес
     приложения — точно такой, как в адресной строке (например,
     https://ваш_логин.github.io/keratin-bar/).
  4. Доступы → «Яндекс.Диск REST API» → отметьте «Чтение всего Диска»
     и «Запись в любом месте на Диске».
  5. Сохраните → скопируйте ClientID.
  6. В приложении (на каждом устройстве): вкладка «Данные и копии» →
     раздел «Яндекс Диск» → вставьте ClientID → «Подключить» →
     разрешите доступ. Готово.

КАК ЭТО РАБОТАЕТ:
- На Диске появится файл «/Кератин Бар/синхронизация_расходы.json».
  Не удаляйте и не редактируйте его вручную.
- Компьютеры могут синхронизироваться тем же способом (кнопка
  «Подключить» в разделе Яндекс Диска) — тогда «файловый мост» не нужен.
- Либо на компьютере продолжайте пользоваться файловым мостом: просто
  создайте файл синхронизации в папке «Кератин Бар» вашего Диска и тем
  именем — тогда компьютер будет идти через диск, телефоны — через
  этот же файл. Пути должны совпадать (проверяется в разделе Яндекс
  Диска, поле «Путь файла на Диске»).


СОВЕТЫ
------
- Фото чека лучше присылать на компьютер в JPG или PNG (iPhone по
  умолчанию присылает HEIC — попросите «отправить как фото»).
- Если интернета нет совсем — распознавание всё равно работает
  (при запуске через основной .bat).
- Сумму можно вводить и через точку, и через запятую: 1250.00 = 1250,00.
